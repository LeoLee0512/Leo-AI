## 发布顺序

1. 校验构建 wheelhouse、两套科学环境和科学 wheelhouse。
2. 执行桌面壳全仓回归与科学环境数值回归；不能把 skip 算作通过。
3. 提交全部源码，确认工作区干净。
4. 使用新的 OutputRoot 构建，核验 EXE 版本、包契约与构建回执。
5. 原位部署，同步 canonical 技能，配置新的科学源码快照。
6. 生成发布清单，执行 `tools/verify_release.py --strict --app-root <安装目录>` 和主题来源校验。
7. 核对部署前后用户数据摘要，保存日志、回执与恢复说明。
