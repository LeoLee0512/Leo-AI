# local-env-check（本机环境查询）

给上游系统提示里那条「涉及外部事实必须先联网」补一个边界：**问的是这台机器或沙盒本身**（`pip list`、包版本、Python 版本、GPU/CPU/磁盘/内存、工作区文件）时，直接执行一条命令，不要先 `web_search` / `web_fetch`。

- 起因：2.2.9 实测里，AI 执行 `pip list` 之前先尝试联网抓取和搜索，白白多走两步，还可能失败。
- 做法：上游每轮把技能名和一行描述拼进系统提示，所以这句引导不写进对话记录、不改上游代码。描述在 200 字以内，超过会被截断。
- 只读：安装、升级、卸载包不在此技能范围内，仍走审批。
- 生效方式：`tools/sync_skills.py` 把 `skills/` 推到已安装目录的 `user/user-skills/` 和 WSL 守护进程读取的目录；发版时 `verify_release --strict` 会核对这两处与仓库一致。
